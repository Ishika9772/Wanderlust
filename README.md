# Wanderlust 🌍

A full-stack web application inspired by Airbnb that allows users to explore, create, and review travel listings.

## 🚀 Live Demo

🔗 Live Project: https://delta-project-t875.onrender.com/

## 📂 GitHub Repository

🔗 https://github.com/Ishika9772/Wanderlust

## ✨ Features

* User authentication (Signup / Login / Logout)
* Create, edit, and delete property listings
* Add and delete reviews
* Image upload using Cloudinary
* Interactive map for location
* Responsive UI design
* Secure authentication with sessions

## ⚙️ Installation

Clone the repository:

git clone https://github.com/Ishika9772/Wanderlust.git

Install dependencies:

npm install

Create a .env file and add the following variables:

ATLASDB_URL=your_database_url

CLOUDINARY_CLOUD_NAME=your_cloud_name

CLOUDINARY_KEY=your_key

CLOUDINARY_SECRET=your_secret

SESSION_SECRET=your_secret

Run the project:  npm start

Open in browser: http://localhost:8080
